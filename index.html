A desktop tool that runs 22 health and security checks against Active Directory and produces a graded report.

Outcome One run gives a prioritised list of what to fix, exported as an HTML report with expandable details or as CSV.

Active Directory security audit and hardening

Audited the lab domain with my own PowerShell tools, fixed the real findings and enforced tiered administration with Group Policy.

Outcome Health Check findings went from 14 to 1 (an intended, documented one), admin accounts can sign in only to their own tier, and three audit tools were corrected after their output was checked against raw data.

Problem, approach and detail
  • Problem A new domain carries default weaknesses, and admin accounts that can sign in anywhere leave credentials exposed on every machine they touch.
  • Approach Baseline reports first (AD health, privileged accounts, NTFS permissions), separate real findings from false positives, fix with logged scripts that are safe to run again, then rerun the same reports.
  • Findings fixed: AD Recycle Bin enabled, PDC emulator on an external NTP source, built-in Administrator password rotated with expiry restored, Guest account hardened, "password never expires" removed from service accounts.
  • Identity hardening: fine-grained password policies for service accounts (20+ characters) and admin accounts (16+ characters, lockout), Tier 0 admin in Protected Users, machine account quota set to 0 with domain join delegated to one service account on two OUs.
  • Tier separation with three GPOs: domain controllers accept Tier 0 only; servers make the Tier 1 group local administrators and deny Tier 0 and Tier 2 every logon type; workstations do the same for Tier 2. Verified with sign-in tests on each tier.
  • Tool validation: the Health Check reported false positives (lingering objects on a single DC, built-in groups as empty, new accounts as inactive); the permission scanner silently reused the previous folder's data when access was denied; the privileged account report missed nested membership. All three fixed.
