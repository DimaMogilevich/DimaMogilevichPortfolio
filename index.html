License Audit Console

A desktop app that shows who actually uses their Microsoft 365 licence, using on-premises and cloud sign-in evidence side by side.

Problem

Licence reviews needed last-logon and activity data for thousands of accounts, pulled by hand from Active Directory, Microsoft 365 usage reports and Entra ID sign-in logs, then merged in Excel.

Approach

Single-file PowerShell WPF app that queries AD and Microsoft Graph, merges three activity signals per user and caches results locally with a 7-day freshness window.

Outcome

One console replaces three manual report pulls. Inactive E5 licences come out as a list with evidence attached, ready for reclaim.

Technical detail
  • Search by AD group or individual user: sAMAccountName, UPN or display name, including non-Latin names.
  • Three checks: AD lastLogonTimestamp, Graph Microsoft 365 app activity, Graph sign-in activity. Optional E5-only filter.
  • JSON caches per source, scan history tab with archive, CSV export of results.
  • Graph sign-in runs in a separate PowerShell process with WAM disabled; Run stays disabled until the connection succeeds.
  • Least-privilege scopes: AuditLog.Read.All, Reports.Read.All, User.Read.All.

AD Privileged Account Manager

Finds accounts left marked as privileged after leaving admin groups, and cleans them up in a controlled three-step flow.

Problem

Accounts that were once in admin groups keep adminCount=1 and have permission inheritance disabled by AdminSDHolder. They look privileged in audits and delegated permissions stop applying to them.

Approach

Pick OUs in a tree, scan for users with adminCount=1 and show which of eight built-in privileged groups each still belongs to. Then remediate only the selected accounts.

Outcome

Leftover admin flags are removed with confirmation at each step, and normal delegation works again for those accounts.

Technical detail
  • Three tabs: select OU (this OU only or with sub-OUs), scan results, remediation.
  • Remediation actions: clear adminCount, remove from a chosen privileged group, re-enable ACL inheritance.
  • Checks for elevation at start and warns about the impact before any change.
  • Works against any domain entered at startup.

Lessons from the console

Field notes

Short fixes that cost hours the first time. Collected while building the tools above.

Save .ps1 files as UTF-8 with BOM

Windows PowerShell 5.1 reads a BOM-less file as ANSI and mangles any non-ASCII character. Keep scripts plain ASCII and save with BOM.

Console prompts freeze WPF tools

Get-Credential and $Host.UI.PromptForCredential are console-bound. Launched with "Run with PowerShell", a GUI tool can hang on them. Build a WPF credential dialog instead.

Silence PowerCLI first-run prompts once

The CEIP and multi-server prompts are interactive. Set them at startup, once, so a button click never triggers them.

Set-PowerCLIConfiguration -Scope User `
  -ParticipateInCEIP $false `
  -DefaultVIServerMode Single -Confirm:$false

Connect-VIServer wants a bare hostname

A pasted https://vc01.mylabenv.local/ fails. Strip the scheme and trailing slash before connecting.

file:// pages cannot fetch local JSON

Browsers block it. Embed the data in a script tag inside the HTML when the report is generated.

Use .Replace(), not -replace, to inject content

-replace is regex, so a $ in the injected text becomes a back-reference. The string method is literal.

$html = $template.Replace('/*DATA*/', $json)

Excel export with zero libraries

For offline tools, write SpreadsheetML XML in the browser and save it through a Blob. Excel opens it natively, with multiple sheets.

Declare before the first synchronous trigger

When data is embedded, the render chain can fire during page load. Any const or let it touches must be declared above that point.

RSAT offline on Windows 11 24H2

When Add-WindowsCapability fails offline, install the CAB from the Features on Demand ISO directly.

DISM /Online /Add-Package /PackagePath:<FoD>\<rsat-cab>

Get-Credential in 5.1 has no -Title

Only -Message is supported in Windows PowerShell 5.1. Scripts written for PowerShell 7 break on it.
